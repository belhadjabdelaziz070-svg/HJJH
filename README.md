# AADL 3 Housing Platform

A modern Algerian housing assistance and application follow-up platform for AADL 3 applicants.

## Features
- Premium RTL landing page in Arabic with French support
- Registration form with document uploads
- Automatic tracking number generation
- Application status tracking
- Admin dashboard with authentication, filtering, editing, archive, and export
- SQLite database persistence
- Secure admin login
- WhatsApp and contact support

## Tech stack
- Node.js + Express
- SQLite
- Multer for document uploads
- XLSX export
- Session-based admin authentication

## Local setup
1. Install dependencies:
   npm install
2. Start the platform:
   npm start
3. Open in browser:
   http://localhost:3000
4. Admin login:
   username: admin
   password: Admin@123

## Admin dashboard
Open: http://localhost:3000/admin

## Important note
This project is an independent assistance and follow-up platform and is not the official AADL website. It is intended to help applicants manage and track their applications.
